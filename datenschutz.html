Zweck

Der Morosov Familien-Assistent ist eine private Anwendung für den eigenen Haushalt. Sie nutzt die Google Calendar API und die Gmail API ausschließlich für die Google-Konten des Betreibers und seiner Familie, die der Nutzung selbst zugestimmt haben.

Welche Daten verarbeitet werden

  • Kalendereinträge (lesen und erstellen von Terminen und Fristen)
  • E-Mails (lesen, Entwürfe erstellen, versenden nur nach ausdrücklicher Freigabe)

Speicherung und Weitergabe

Die Daten werden nur auf einem privaten Server im Haushalt des Betreibers verarbeitet. Zugangsschlüssel werden verschlüsselt gespeichert. Es findet keine Weitergabe an Dritte statt, keine Werbung, kein Verkauf und keine Auswertung zu anderen Zwecken.

Die Nutzung der über Google-APIs erhaltenen Daten entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf und Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Auf Wunsch werden gespeicherte Zugangsschlüssel sofort gelöscht.
